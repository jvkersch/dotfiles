* Nethack

Requires a custom build of Nethack and is currently only available for manual install. See [[https://github.com/Feyorsh/nethack-el][nethack-el]] for instructions.

#+BEGIN_SRC elisp
  (add-to-list 'load-path "~/.emacs.d/src/nethack-el")
  (require 'nethack)
#+END_SRC
